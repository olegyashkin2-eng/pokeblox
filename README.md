# Pokeblox 0.9.0 — четыре острова и 77 готовых 3D-моделей

Играть: https://pokeblox-olegya88.mia0.amvera.tech/

Обновление по двум фотографиям игрока. Первые 15 моделей Канто сохранены. Все 16 самодельных моделей Приливного острова заменены готовыми GLB с текстурами; ещё 46 видов добавлены из того же набора. Все 77 моделей поставляются внутри игры, вместе с Draco. Процедурные скульптуры и кубические модели больше не используются. Источники, размеры, сведения о геометрии и SHA-256 файлов находятся в `public/assets/sources.json`.

## Острова и правила фотографий

- **Канто:** прежняя карта, Пикачу в начале, Иви с шансом 5% в своих зонах, Чаризард 0,5% в янтарных скалах. Первые задания и все прежние эволюции сохранены.
- **Приливный остров:** прежние обитатели и босс Голдак; добавлены Старью, Старми, Дратини, Драгонэйр, Драгонайт, Артикуно и Лапрас. Три места редких встреч у берега отмечены звёздочками на карте. При каждом появлении: Артикуно 0,005%, Дратини 0,5%, Лапрас 20%, Старью 49,495%, Старми 30%. Это шансы появления, не поимки. Драгонэйр и Драгонайт встречаются только через эволюцию; каждая требует одного драконьего камня, расположенного на втором острове.
- **Долина кактусов:** Сэндшрю, Сэндслэш, Манки, Праймейп, Мачоп, Мачок, Мачамп, Хитмонли и Хитмончан. Песчаные террасы, кактусы, оазис, арена и табличка «Это сделал не я, это был кактус!».
- **Волшебный лес:** все 30 видов с фотографии: Джигглипафф, Вигглитафф, Клефейри, Клефейбл, Оддиш, Глум, Вайлплум, Парас, Парасект, Венонат, Веномот, Абра, Кадабра, Алаказам, Беллспраут, Випинбелл, Виктрибелл, Дроузи, Гипно, Ликитунг, Мистер Майм, Джинкс, Дитто, Поригон, Катерпи, Метапод, Баттерфри, Видл, Какуна и Бидрилл. Лес примерно в 1,8 раза больше остальных островов по площади, с высокими розовыми и жёлтыми деревьями, грибной тропой, лунной поляной и озером снов. Есть лунный и лиственный камни.

**Лапрас не участвует в боях.** Встреча с ним мирная: кнопка «Подружиться с Лапрасом» открывает дальние маршруты. Он появляется в покедексе, но не занимает место бойца. После трёх побед Лапрас-проводник позволяет добраться до второго острова и вернуться; свой Лапрас открывает третий и четвёртый. Каждая поездка показывает отдельную 3D-сцену плавания с тренером на спине. Остров назначения сохраняется до сцены: закрытие вкладки во время поездки не теряет прогресс.

Базовые характеристики 77 видов проверены по PokeAPI CSV от 2026-09-30; максимальная сумма у Драгонайта — 600. Изменённые правила эволюций явно показаны в покедексе: Гравелер, Мачок и Кадабра достигают последней формы на 36 уровне без обмена, Дратини и Драгонэйр используют драконий камень. Мэджикарп и Шелдер пока остаются в своих формах.

## Модели, анимации и экран

Скелеты и доступные именованные анимации GLB используются напрямую; там, где клипов нет, применяются движения суставов и отдельные профили видов. Обычный и особый удар имеют разные движения и эффекты; урон совпадает с моментом попадания. Эволюция показывает свечение цвета камня, смену силуэта и новую форму в отдельной 3D-сцене. Модели без скелета сохраняют движение целиком.

На телефоне и планшете работают обе ориентации: камера, джойстик, боевые кнопки, панели, эволюция и поездки подстраиваются при повороте. WASD/стрелки — движение; E — действие; Q — команда; P — покедекс; B — рюкзак; M — карта; Shift — бег; пробел — прыжок. Лечение в лагере бесплатное.

Установка PWA доступна на стартовом экране. На iPhone: Safari → Поделиться → На экран Домой. Чтобы получить обновление ранее установленной игры, закрой все окна игры и открой её снова с интернетом.

Сохранения v2 и v3 автоматически переходят в v4. Команда, идентификаторы покемонов, инвентарь, бои, победа над Голдаком и старые ключи объектов сохраняются. Четыре карты хранятся отдельно. Старый клиент не может перезаписать сохранение новой версии. Схема SQLite и существующие аккаунты не меняются.

## Аккаунты и сохранения

Любой посетитель может зарегистрироваться с логином и паролем. Почта не требуется. Команда, уровни, опыт, здоровье, инвентарь, задания, открытые формы, место и камера на карте, перезарядка предметов, дикие покемоны, звук и текущий бой сохраняются отдельно для каждого аккаунта.

Сохранение отправляется после игровых действий, каждые 5 секунд и при уходе со страницы. Надпись «Сохранено» означает подтверждение сервера. При обрыве связи браузер хранит очередь неотправленных изменений в IndexedDB и повторяет отправку. На другом устройстве доступен последний подтверждённый сервером прогресс. Очистка данных браузера удалит неотправленный черновик.

Две одновременно открытые игры не перезаписывают друг друга молча: при конфликте нужно загрузить последнее серверное сохранение. Результат хода фиксируется перед анимацией, поэтому перезагрузка во время поимки не выдаёт покемона повторно.

Пароли хранятся как scrypt-хеши с индивидуальной солью. Сессии — HttpOnly/SameSite cookie, в production также Secure. Есть проверка CSRF и ограничение попыток входа. Сессия действует 30 дней; после повторного входа прогресс остаётся. Восстановление забытого пароля по почте пока не реализовано.

## Локальный запуск

Нужен Node.js 24. Пакетов npm для работы сервера не требуется.

```sh
npm test
npm start
```

Игра откроется на http://localhost:3000. По умолчанию база находится в `data/pokeblox.db`.

## GitHub → Amvera

1. Создать отдельный репозиторий `pokeblox-kanto` и загрузить **содержимое** этого проекта в его корень. `amvera.yaml` и `Dockerfile` должны лежать рядом. Базу данных и файлы `.env` не загружать.
2. В Amvera создать отдельное приложение, выбрать сборку Docker и загрузить код из репозитория. Существующее приложение «Котость» для этого не используется.
3. В конфигурации уже заданы порт `3000` и постоянная папка `/data`. Переменная `DB_PATH=/data/pokeblox.db` задана в Dockerfile. Оставить **одну реплику**: эта версия использует локальный SQLite.
4. Подключить предоставленный Amvera HTTPS-домен. После получения домена рекомендуется задать `PUBLIC_URL` равным его адресу, без пути. HTTP в production не поддерживает защищённую cookie входа.
5. Запустить сборку и приложение. Проверить `/healthz`, затем регистрацию, вход, сохранение и продолжение после перезагрузки страницы. Обновление GitHub само по себе не гарантирует запуск сборки — проверить настроенную интеграцию или отправить изменения в Git Amvera.

Если используется Git Amvera, адрес remote нужно скопировать из конкретного проекта:

```sh
git remote add amvera <адрес-из-Amvera>
git push amvera main:master
```

`/data` должна оставаться постоянным хранилищем при пересборке и перезапуске. Приложение проверяет создание резервной копии каждый час, делает одну копию в день и хранит семь последних в `/data/backups`. Это копии на том же диске; удаление хранилища Amvera удалит и их. Для независимого резервирования скачивать копии отдельно. Для восстановления остановить приложение и заменить базу согласованной копией; не копировать только основной SQLite-файл работающей базы без WAL.

## Проверки и ограничения

`npm test` использует реальные GLTFLoader и Draco для всех 77 GLB, проверяет размеры, независимость скелетов, попадания, эффекты и размещение бойцов на девяти размерах/ориентациях экрана. Дополнительно проверены точные вероятности редких встреч, все новые камни, отсутствие Лапраса в боях, доступность встреч и предметов в новых сценах, поездки, миграция старых сохранений, конфликт старой вкладки, аккаунты и восстановление всех четырёх островов после настоящего перезапуска тестового сервера.

В Node текстуры заменяются заглушкой для проверки геометрии; файлы изображений отдельно распакованы и проверены. Облачный проверочный браузер не поддерживает WebGL, поэтому полноценная проверка картинки и производительности на физическом телефоне не выполнена.

Это одиночная игра с личными сохранениями. Сервер проверяет формат прогресса; полного серверного античита нет.
